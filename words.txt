# words.txt -- the British -> American word list for check-american-spelling.py.
#
# This file is the ONLY source of the list; the script holds no words of its own.
#
# Format: one `british american` pair per line, both lower case ASCII letters,
# separated by whitespace. Every inflection is its own line: there is no suffix
# rule, because a suffix rule flags words that are already American (promise,
# exercise, otherwise; four, hour; more, there). A line starting with `#` is a
# comment; blank lines are ignored. A malformed line, a British word listed
# twice, or a pair mapping a word to itself makes the gate exit 2.
#
# Before adding a word, make sure it is not also an American spelling of
# something else ("analyses", "licensed" and "practice" are, so they are absent).
#
# The last section holds the SUBSTRING STEMS: `substring <stem> <american>`
# lines. A stem is also matched INSIDE a word piece that is not listed whole, so
# compounds with no separator (colourpick, bgcolourx) are caught. Add a stem
# only if it never occurs inside an American word: "glamour" is American too,
# so it is absent, and "grey" is absent because it occurs inside "greyhound".
# A stem found inside an American spelling in this file makes the gate exit 2.
