# allow.txt -- the PUBLIC allow list for check-american-spelling.py.
#
# It may name PUBLIC repositories only. CI runs check-allow-public.py, which
# fails unless every repository named here answers the unauthenticated GitHub
# API as public; run it yourself before pushing a change to this file.
# Private repositories keep their exceptions in a private allow file outside
# this repository (see the README, "Private repositories").
#
# An entry exempts one British word on the paths of one repository, for a
# FIXED EXTERNAL IDENTIFIER that cannot be Americanized: a library's own
# parameter, a protocol or API value, a file name another system owns.
#
# Format: `<owner/repo> <path-glob> <word>`, one entry per line.
#   owner/repo  the GitHub slug of the scanned repository (case-insensitive);
#               the gate gets it from --repo-slug, or from the `origin` remote
#   path-glob   repo-relative; `*` and `?` stay inside one directory, `**/`
#               spans any number, and `**` alone matches every path
#   word        lower case, and present in words.txt
# Every entry sits under a `#` comment giving its reason; one comment covers
# every entry that follows it, up to the next blank line. An entry with no
# reason, a malformed line or an unknown word makes the gate exit 2. Entries
# apply to files only, never to commit messages; a single line is better
# served by the inline marker `spelling: allow`.
#
# Adding an exception is a pull request to this repository and a new tag; a
# consumer picks it up by bumping the tag it pins.
